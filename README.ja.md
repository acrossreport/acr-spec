
## ACR 仕様

ACR (Across Report) は、モダンなソフトウェアシステム向けに設計された、プリンタ非依存の帳票仕様です。

> **一度レンダリングすれば、どこでも出力できる。**

ACR はレイアウト定義・レンダリング・出力生成を明確に分離しており、同一のテンプレートを複数のプラットフォームおよび出力形式で利用できます。

---

### なぜ ACR か

従来の帳票システムは、特定のプリンタ・レンダリングエンジン・フレームワークと密結合しています。これにより、プリンタドライバの更新で出力が壊れたり、新しいプラットフォームへの移植にゼロからの書き直しを強いられるといった問題が生じます。
